# Square Calculator using Streamlit

A simple and interactive web application built with **Python and Streamlit** that calculates the square of a number selected by the user.

## 🚀 Features

- Interactive number slider
- Calculates the square instantly
- Simple and user-friendly interface
- Built using Python and Streamlit
- Easy to deploy and share online

## 🛠️ Technologies Used

- Python
- Streamlit
